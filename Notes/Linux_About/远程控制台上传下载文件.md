## rz sz命令实现 (SSH下)
[返回主页马踏飞燕Beautiful.博客园](https://cnblogs.com/Formulate0303/p/17385451.html)
这两个命令可以直接上传、下载文件，并自动弹出文件选择框，操作非常方便和习惯。但是要使用的话，需要远程Linux服务器安装了这两个命令，也就是安装了lszrz包。
### rz命令
rz 命令(Receive ZMODEM)，使用 ZMODEM 协议，将本地文件批量上传到远程 Linux/Unix 服务器，注意不能上传文件夹。
```
cd [目标路径]
rz
```
输入 rz 回车后，会出现文件选择对话框，选择需要上传文件，一次可以指定多个文件，上传到服务器的路径为当前执行 rz 命令的目录。
![图片](https://img2023.cnblogs.com/blog/1130145/202305/1130145-20230509161242982-1227444631.png)
### sz命令
sz命令是利用ZModem协议来从Linux服务器传送文件到本地，一次可以传送一个或多个文件。
```
sz [目标路径/目标文件.后缀]
```
![图片](https://img2023.cnblogs.com/blog/1130145/202305/1130145-20230509161304069-99174534.png)

## pscp和scp (SSH下)
### pscp
需要安装PuTTY
PuTTY的pscp命令,是基于SSH的命令行工具,用于在Windows和Linux之间安全的传输文件。
下载
``` bash
pscp username@linux_host://path/to/remote/file C:\path\to\local\directory
```
其中,username是Linux系统的用户名,linux_host是Linux系统的IP地址或主机名,/path/to/remote/file是Linux系统上的文件路径,C:\path\to\local\directory是Windows系统上的目标目录。
### scp
如果使用标准的scp命令而不是pscp,需要在Windows上安装OpenSSH客户端。
下载
``` bash
scp username@linux_host://path/to/remote/file C:\path\to\local\directory
```
