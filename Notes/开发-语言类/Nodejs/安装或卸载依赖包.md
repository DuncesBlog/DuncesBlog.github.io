# 安装依赖包
## 为项目添加依赖包
``` DOS/Terminal
npm install express -save
```
    -save ：自动将模块和版本号添加到 dependencies 部分(核心依赖包,在开发期间和项目上线之后都会用到)
    -save -dev ：自动将模块和版本号添加到 devdependencies 部分(开发依赖包)

## 已有项目一次性安装所有包
    可以运行npm install命令(或npm i)一次性安装所有的依赖包
``` Terminal
npm install
```

# 卸载包
    可以运行 npm uninstall +包名 来卸载制定的包(以moment包举例)
``` Terminal
npm uninstall moment
```
注意: npm uninstall命令执行成功后,会把卸载的包,自动从package.json的dependencies中移除掉。




# 全局包
    在执行 npm install 命令时,如果提供了 -g 参数,则会把包安装为全局包。
    全局包通常位于Nodejs安装目录下的 node_modules 文件夹内,可执行文件通常会添加到系统的PATH环境变量中,以便您可以直接在命令行中使用它们。

``` Terminal
npm install -g 包名
npm uninstall -g 包名
```
    注意:
- 只有工具性质的包,才有全局安装的必要性。因为他们提供了好用的终端命令。
- 判断某个包是否需要全局安装后才能使用,可以[参考官方提供的使用说明]()即可。
### 例子-i5ting_toc
``` Terminal
# 将 i5ting_toc 安装为全局包
npm install -g i5ting_toc

# 调用 i5ting_toc,轻松实现md转html的功能
i5ting_toc -f 要转换的md文件路径 -o
```
