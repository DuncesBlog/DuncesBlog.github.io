## CMD 和 命令提示符 的区别
命令提示符（Command Prompt）和CMD（Command Processor）在Windows操作系统中有一些区别，主要体现在名称、启动方式、功能、兼容性、界面和使用场景等方面。
‌
2.功能和兼容性‌：
‌命令提示符‌：提供基本的DOS命令行功能，如文件操作、系统管理等，主要兼容旧版的DOS命令。
‌CMD‌：除了提供基本的命令行功能外，还支持一些高级功能，如环境变量设置、批处理脚本等，兼容新版的DOS命令，同时也支持Windows PowerShell命令‌。
‌
3.界面和使用场景‌：
‌命令提示符‌：界面相对简单，主要是一个纯文本窗口，适用于执行简单的命令行操作，如查看文件、创建文件夹等。
‌CMD‌：界面更加丰富，可以显示更多的信息，如当前目录、历史记录等，适用于更复杂的任务，如系统管理、编程开发等‌。


## CMD 指令
#### ping IP/Address
```
ping 192.168.1.123
ping www.baidu.com
#注意：网络地址前后不能加协议(http:// 或 https://), 后不能加 / ,否则 "Ping 请求找不到主机"
```

#### 查看端口占用
``` CMD
netstat -a -o
# ???
tasklist|findstr "aaaa"
```

#### 查看所有进程占用的端口
``` CMD
netstat -ano
```

#### 查看占用制定端口的程序
查询占用了8080端口的进程,最后一列即为PID
``` CMD
netstat -ano|findstr "8080"
```
