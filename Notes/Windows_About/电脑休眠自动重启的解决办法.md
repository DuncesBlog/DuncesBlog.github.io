
# 电脑休眠自动重启的解决办法
    该文创建于 2024/11/28    文章参考
[zhangzc.知乎](https://zhuanlan.zhihu.com/p/147456304)

## 休眠指令
```
shutdown -h
```


## 表现
当时给电脑休眠，我也准备休眠，快睡着了电脑突然转风扇了(声音有点大……),就又给电脑鼠标一翻再次休眠了我继续睡
第二天起来发现电脑又是工作状态……
休眠!然后发现基本是整点唤醒!所以应该是电脑有什么定时计划吧电脑唤醒了(之前鼠标翻过来了,不可能是键鼠移动造成的)

## 解决
参照[zhangzc.知乎]的文章,我没有直接去查[计算机管理]的任务,而是先查了一下该文章底部的命令提示符(CMD)指令
``` CMD
powercfg /lastwake
```

结果如图,是什么 "Realtek PCIe GBE Family Controller"
![]()百度一查,是我的网卡,然后'此电脑'--右键-->'管理'---->'设备管理器'---->网络适配器,把网卡的属性里的'允许此设备唤醒计算机'一关,搞定!
